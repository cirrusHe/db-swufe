## 题目二（5分）

如果一个关系模式中只有两个属性，证明该关系模式必定属于BCNF。

答：
假设关系模式 R只有两个属性 A 和  B ，即 R = {A, B} 。
情况分析
1. 没有非平凡的函数依赖：
   如果 R中不存在任何非平凡的函数依赖（即不存在A → B或 B →A），那么根据BCNF的定义，R 自然满足BCNF。因为BCNF的条件是针对非平凡的函数依赖的，而这里没有这样的依赖。
2. 存在非平凡的函数依赖：
   假设存在一个非平凡的函数依赖 A → B 。根据函数依赖的定义，A 能够唯一确定  B 。
   在这种情况下，A 是一个候选键（因为 A 能够唯一标识每个元组），而B依赖于A 。
   根据BCNF的定义，对于函数依赖 A → B，A 是超键（因为A能够唯一标识元组），因此R满足BCNF。
   同理，如果存在B → A，那么B是候选键，R也满足BCNF。
证明：
无论是否存在非平凡的函数依赖，关系模式R= {A, B}都满足BCNF的条件：
如果没有非平凡的函数依赖，根据BCNF的定义， R 自然满足BCNF。
如果存在非平凡的函数依赖（如 A → B 或 B → A ），那么其中一个属性是候选键，另一个属性依赖于该候选键，因此 R也满足BCNF。
因此，一个只有两个属性的关系模式必定属于BCNF。
## 题目三（5分）

考虑关系模式`r(A, B, C, D, E)`，有如下函数依赖：

- A → BC
- BC → E
- CD → AB

请给出一个满足BCNF的分解，并说明你的分解符合BCNF。

答：BCNF分解步骤与结果
1. 判断原关系是否属于BCNF
候选码：通过分析函数依赖闭包，确定候选码为 AD 和 CD（因为它们能推导出所有属性）。
违反BCNF的函数依赖：
  A → BC：决定因素A不是超码（候选码为AD或CD）。
  BC → E：决定因素BC不是超码。
因此，原关系模式 `r(A, B, C, D, E)` 不属于BCNF，需要分解。
 2. 基于A → BC进行第一次分解
分解出关系：
  r1(A, B, C)：包含函数依赖A → BC（A是候选码，满足BCNF）。
  r2(A, D, E)：原依赖BC → E在r2中不适用，剩余依赖需重新分析。
r2中的函数依赖：
A → E（从原依赖A → BC和BC → E传递得到）。
候选码为 AD（A不能单独决定D）。
违反BCNF：A → E的决定因素A不是超码。
3. 基于A → E分解r2
分解出关系：
  r3(A, E)：包含函数依赖A → E（A是候选码，满足BCNF）。
  r4(A, D)：无函数依赖，候选码为AD，满足BCNF。
4. 处理剩余依赖CD → AB
原依赖CD → AB 在分解后：
   AB 属于`r1(A, B, C)`，但CD不在同一关系中。
  需要引入`r5(C, D, A)` 以保留CD → A的依赖（CD是候选码）。
最终BCNF分解结果
分解后的关系模式为：
1. r1(A, B, C)  
   函数依赖：A → BC  
   候选码：A  
   满足BCNF：决定因素A是候选码。
2. r3(A, E)  
   函数依赖：A → E 
   候选码：A  
   满足BCNF：决定因素A是候选码。
3. r4(A, D) 
   无函数依赖  
   候选码：AD
   满足BCNF：无非平凡函数依赖。
4. r5(C, D, A) 
   函数依赖：CD → A  
   候选码：CD  
   满足BCNF：决定因素CD是候选码。
验证分解符合BCNF
所有关系均满足BCNF：每个关系的决定因素均为候选码。
无损连接性：分解后的关系通过自然连接可恢复原关系。
函数依赖保持：
  A → BC 在 r1 中保留。
  BC → E 由 r1 和 r3 间接保持（A → BC → E）。
  CD → AB 由 r5 和 r1 共同保持（CD → A，A → BC）。
因此，该分解满足BCNF要求。
